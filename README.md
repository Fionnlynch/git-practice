# 🚀 Git & GitHub Acceleration Sprint

A hands-on repository dedicated to mastering professional version control, local development rhythms, and cloud-based project automation within a compressed timeline.

## 🛠️ Tech Stack & Environment
* **OS:** macOS (Unix / Zsh)
* **Editor:** Visual Studio Code
* **Version Control:** Git & GitHub Cloud

## 🧠 Core Competencies Mastered
* **The Local Development Loop:** Regular tracking, staging, and atomic snapshots (`git status`, `git add .`, `git commit`).
* **Isolated Branching Workflow:** Safe experimentation utilizing feature sandboxes (`git checkout -b`) and consolidating parallel code timelines.
* **Merge Conflict Resolution:** Deliberately engineered timeline clashes, manually parsing Git conflict markers (`<<<<<<<` and `>>>>>>>`), and safely merging resolutions.
* **Cloud Infrastructure Sync:** Managing remote repositories via `git push`, `git pull`, and upstream tracking configurations.
* **Agile Project Automation:** Mapping development goals to live GitHub Issue tickets, linking them to visual Kanban Project Boards, and using terminal keyword scripts (`Closes #1`) to automate task pipelines.

## 📁 Repository Structure
* `notes.txt`: Core technical logs, documentation, and curriculum reference material.
* `.gitignore`: Custom configurations designed to isolate repository code from local system clutter (e.g., Mac `.DS_Store` files).
